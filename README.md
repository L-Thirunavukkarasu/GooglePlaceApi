# React Native Places Search App

A React Native application that integrates Google Places API for searching locations, displays selections on a map, and persists search history locally.

## Features

- Real-time place autocomplete using Google Places API
- Map display with markers (`react-native-maps`)
- Persistent search history with AsyncStorage
- Tap on history to re-center the map
